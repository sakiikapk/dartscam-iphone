# BoardCam(ダーツの着弾を iPhone で取るアプリ)

ダーツボードを iPhone で映しっぱなしにして、**刺さった位置(mm)だけ**を端末の中で取るアプリ。
動画は保存しないので容量を食わない。結果は CSV で出て、
[darts-home](https://github.com/sakiikapk/darts-home) の解析(フォームとの突き合わせ、レポート、ハイライト)にそのまま流せる。

- 盤面: ソフト 15.5インチ(DARTSLIVE Home など、ダブル外径 Ø393.7mm)/ハード(スティール公式、Ø340mm)/カスタム径。設定(歯車)で切り替え
- 対応: iOS 17 以上の iPhone。縦持ち・横持ちどちらでも OK。縦持ちでは操作ボタンが画面の上に半透明で重なる(下が台座で隠れてもよい)
- 外部ライブラリなし(Swift + SwiftUI + AVFoundation だけ)

---

## 使い方

### 1. iPhone を置く

- 盤全体が画面に入るように **固定** する(三脚・スタンド・棚など)。投げている間に動くと座標がずれる
- おすすめは **盤の正面〜やや上から見下ろす** 位置。斜め下から撮ると、手前に出たフライトでチップが隠れやすい
- 距離は 1〜1.5m くらい。盤が画面の半分以上を占めると精度が上がる(キャリブレーション画面の「px/mm」が 1.0 以上が目安)
- 部屋の明るさは記録中なるべく変えない(照明のオンオフで誤検出する)

### 2. キャリブレーション(置いたら「自動キャリブレーション」を1回)

- 「自動キャリブ」を押すだけ。盤の赤青のマス(ハードなら赤緑)を色で拾って、
  ブルとダブル・トリプルの位置から画面↔mm の対応を解く。水色の線が盤に重なれば OK
- 条件: 盤全体(少なくともダブルのマスが10個以上)が明るく映っていること。暗い・逆光・盤が小さすぎると失敗する
- 20 の位置(回転)は「画面の上」を手がかりに決める。縦持ち・横持ちどちらでも OK。
  それでも 20 がずれているときは「20がずれてる」→ 画面の 20 を1回タップ。以降その向きで合わせる
- 「記録スタート」のたびに自動で合わせ直すので、置き直したあとに押し直す必要はない。
  記録中にダーツを抜いたタイミングでも盤を見直して、カメラが 3px 以上ずれていれば勝手に追従する
- 自動がどうしても通らないときだけ「手動(5点タップ)」: 止めた1枚の上でブル中心と
  20/6/3/11 のダブル外側のふちを順に押す(押したまま指をずらすと拡大鏡で合わせられる)。
  iPhone に触るので、押し終わってから置き直したときはもう一度「自動」か「記録スタート」で合わせ直す

### 3. 記録

1. 「記録スタート」。このとき露出・ピント・色が固定される
2. 普通に投げる。刺さって揺れが止まったら(約0.3秒)点が打たれる
   - 黄色: 直近3本 / 緑: それ以前 / オレンジ: チップが見えなかった(位置は推定) / 水色: 手で直した点
3. 点がずれていたら **ドラッグで正しい位置に動かす**(拡大鏡が出る)。直した点は `note=manual` になる
4. 3本投げてダーツを抜くと、それを検知して次のラウンドに進む(抜いた動きは着弾として数えない)
5. 間違って拾ったら「最後の1本を消す」
6. 終わったら「記録おわり」

画面の右(縦持ちなら下)に、今のラウンド(例 `R5: T20 S1 BULL = 111`)、本数、σ、1ラウンド平均、狙いに入った率、平均のずれが出る。
刺さると音とバイブで知らせる(設定でオフにできる)。

### 設定(歯車)

- 盤の種類: ソフト 15.5インチ / ハード / カスタム(ダブル外径を mm で入力)。ソフトはセパレートブル(外25/内50)も選べる
  - 変えてもタップし直す必要はない(同じ5点で新しい寸法として解き直す)
- 狙い: BULL / T20 / T19 / T18 / T17 / T16 / T15。ずれ・命中率はここ基準
- 音とバイブのオンオフ

### まとめ・履歴

- 「まとめ」: 盤を正面から見た図に全部の矢、平均(+)、1σ/2σ の楕円、狙いを重ねて表示。
  σ、平均のずれ(「左に12mm・上に5mm」)、半分の矢が入る円、命中率、1本/1ラウンド平均、レーティング目安(BULL狙いのとき)、ラウンドごとの点数
- 時計マーク: 過去のセッション一覧。開くと同じまとめが見られる(点数は今の盤設定で計算し直す)

### 4. データを取り出す

- iPhone の「ファイル」アプリ → このiPhone内 → BoardCam → `sessions/<日時>/`
- 記録おわりの後に「CSVを送る」で AirDrop などでも送れる

## 出力ファイル

`sessions/YYYY-MM-DD_HHMMSS/` に1セッション分:

| ファイル | 中身 |
| --- | --- |
| `hits.csv` | 1本1行の着弾データ(下の表) |
| `hitNNN_a.jpg` / `hitNNN_b.jpg` | 着弾の直前 / 直後の静止画(960x540)。後で Mac で再計算・確認するため |
| `calib.jpg` | 記録スタート時の1枚 |
| `calibration.json` | キャリブレーション(タップした5点と変換行列) |

### hits.csv の列

最初の8列は darts-home の `src/board.py` が出す `hits.csv` と同じなので、そのまま `src.session` に渡せる。

| 列 | 意味 |
| --- | --- |
| `hit_no` | 通し番号 |
| `frame` | 記録開始からのフレーム番号(30fps 換算) |
| `time_s` | 記録開始からの秒(動き始め = 着弾の瞬間) |
| `tip_x_px`, `tip_y_px` | チップの画像上の位置(1920x1080 換算、カメラ本来の横向き) |
| `x_mm`, `y_mm` | 着弾座標。ブル中心が原点、+x が 6 の方向、+y が 20 の方向。チップが見えなかった本は空 |
| `note` | 空 = 自動で取れた / `tip_hidden` = チップが隠れていた / `no_dart_found` = ダーツが見つからない / `manual` = 手で直した |
| `wall_time` | 着弾の実時刻(ミリ秒まで、例 `2026-10-29T21:03:11.482+09:00`)。フォーム動画との同期用 |
| `r_mm` | ブルからの距離 |
| `theta_deg` | 角度。6 の方向が 0°、反時計回り、20 の方向が 90° |
| `segment` | 当たったところ(`BULL` / `T20` / `D6` / `S1` / `OUT`)。リング幅は darts-home の `report.py` と同じ近似 |
| `img_before`, `img_after` | 前後の静止画のファイル名 |
| `round_no` | ラウンド番号(ダーツを抜いたとき、または3本ごとに進む) |
| `score` | その1本の点数(盤設定に従う。ソフトのファットブルは50、ハード/セパブルは 25/50) |
| `board` | 使った盤の設定名 |

## darts-home の解析につなぐ

```
# 1. hits.csv を Mac に持ってくる(例: data/sessions/2026-10-29/board_hits.csv)

# 2. フォーム動画もあるとき: 今まで通り姿勢を出して突き合わせる(同期は自動)
python -m src.pose data/sessions/2026-10-29/form.mov
python -m src.session data/sessions/2026-10-29/form_pose.csv data/sessions/2026-10-29/board_hits.csv --thrower ryo

# 3. 盤面だけの日は hits.csv 単体で σ や分布が見られる
```

同期は `src.session` が「リリースの 0.05〜0.6 秒後に着弾」が一番多く合うずれを自動で探す。
`wall_time` があるので、フォーム側の撮影開始時刻とでも大まかに合わせられる。

## しくみ

1. **キャリブレーション**: 色で拾ったマスの重心とブルを、盤上の既知の位置(mm)に対応づけてホモグラフィ(射影変換)を
   RANSAC で解く。どのマスが何番かは「色の偶奇」と「20 が上」で決める(`AutoCalib.swift`、darts-home の `board.py` と同じ)。
   手動は5点タップから同じ変換を最小二乗で解く(`BoardGeometry.swift`)
2. **動きの検出**: 30fps の映像を半分(960x540)に縮め、盤の周りだけ4画素おきに前のフレームと比べる。
   しきい値はノイズの中央値 + 4MAD で自動(`Detector.process`)
3. **着弾の判定**: 動きが 0.3 秒止まったら、動く前と後を色ごとに比べる(明るさの揺れは中央値でそろえる)。
   - 変化がダーツ1本ぶん(見かけ 150mm x 10mm の目安)→ 着弾
   - ずっと大きい / 2秒以上動いた / 盤に3本刺さっている → ダーツを抜いた・人が通ったとみなしてリセット
4. **チップ位置**: 差分の塊に直線を当て、キャリブレーションから計算した「その位置に垂直に刺さったダーツが画面上で
   伸びる向き」を使って、**盤面に近い端**をチップとする。フライトが一番大きく写る斜め下からの撮影でも
   取り違えないようにしてある(darts-home の `src/board.py` の `find_tip` と同じ考え方)
5. **向き**: 処理と保存はいつもカメラ本来の横向き。縦持ちのときは表示とタップの座標だけ回している

| ファイル | 役割 |
| --- | --- |
| `BoardCamApp.swift` | 起動、画面スリープ止め |
| `Camera.swift` | 背面カメラ 1080p30、露出などのロック、撮影時刻 |
| `RGBImage.swift` | フレームの縮小・回転・JPEG 化 |
| `AutoCalib.swift` | 盤の色からの自動キャリブレーション |
| `BoardGeometry.swift` | 盤の種類と寸法、点数、狙い、ホモグラフィ、ダーツの向き |
| `Detector.swift` | 動き検出、着弾判定、チップ探し |
| `AppModel.swift` | 画面の状態、セッション、ラウンド、設定、CSV と画像の保存 |
| `Stats.swift` | σ・平均のずれ・楕円・点数の集計、保存済みセッションの読み込み |
| `SummaryView.swift` | まとめ(盤面図)、履歴、設定の画面 |
| `ContentView.swift` | 記録画面、点のドラッグ、拡大鏡 |
| `CalibrationView.swift` | 5点タップのキャリブレーション画面 |

## ビルドして iPhone に入れる(Mac)

必要なもの: Xcode 16 以上、Apple ID(無料で可)、iPhone とケーブル

### はじめて

1. Xcode → Settings → Accounts で Apple ID を追加
2. iPhone をケーブルでつなぎ「このコンピュータを信頼」
3. iPhone の 設定 → プライバシーとセキュリティ → デベロッパモード をオン(再起動される)
4. `BoardCam.xcodeproj` を開き、Signing & Capabilities の Team で自分の Apple ID(Personal Team)を選ぶ
   → 上部で自分の iPhone を選んで ▶
5. iPhone で「信頼されていないデベロッパ」と出たら:
   設定 → 一般 → VPNとデバイス管理 → 自分の Apple ID → 信頼

コマンドでやるなら(**チームIDはリポジトリに入れない**、コマンドで渡すだけ):

```
xcodebuild -project BoardCam.xcodeproj -target BoardCam -sdk iphoneos -configuration Debug \
  DEVELOPMENT_TEAM=<自分のチームID> -allowProvisioningUpdates build
xcrun devicectl list devices
xcrun devicectl device install app --device <iPhoneのID> build/Debug-iphoneos/BoardCam.app
```

### 7日ごとの入れ直し

無料の Apple ID で入れたアプリは **7日で期限切れ** になり開かなくなる(Apple の決まり)。
記録したデータは消えない。上と同じ手順で入れ直せば戻る(「信頼」のやり直しは不要)。
年 $99 の Apple Developer Program に入ると1年もつ。

## 気をつけること・今後

- 精度の目安: 盤が画面いっぱいに近いほど良い。キャリブレーションのタップが 1〜2mm、チップ検出が数mm
- まだ実際の投擲での精度確認をしていない。最初の1回は盤面を動画でも撮って、darts-home の `src/board.py` の結果と比べるのがおすすめ
- 苦手: 照明が変わる、カメラが動く、盤の前を人が横切ったまま止まる、チップが前のダーツのフライトに隠れる
- 今後: フォーム側(体の関節)の端末処理
